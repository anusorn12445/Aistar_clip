🏛️ แก่นแบรนด์ Brand Foundation

Mission

ให้ผู้หญิงไทยทุกสภาพผิวมั่นใจได้ด้วยสกินแคร์จากธรรมชาติ ราคาจับต้องได้

Vision

แบรนด์สกินแคร์ธรรมชาติอันดับหนึ่งในใจคนไทย ภายในปี 2028

Core Values

จริงใจ โปร่งใสเรื่องส่วนผสม ยั่งยืน

Positioning

สำหรับสาววัยทำงานผิวแพ้ง่าย NARA คือสกินแคร์ธรรมชาติที่อ่อนโยนแต่เห็นผลจริง — ต่างจากแบรนด์เคาน์เตอร์ตรงราคาเข้าถึงได้ และต่างจากแบรนด์ถูกตรงส่วนผสมที่เปิดเผยทุกตัว

บุคลิกแบรนด์ (Archetype)

The Caregiver — เพื่อนสาวคนโตที่รู้เรื่องผิว: อบอุ่น ให้คำแนะนำแบบไม่ตัดสิน ไม่ hard-sell

📖 เรื่องราว & จุดขาย จาก Brand Knowledge เดิม

เริ่มจากคุณนารา เภสัชกรที่ผิวแพ้สเตียรอยด์จากครีมไม่ได้มาตรฐาน จึงพัฒนาสูตรจากสมุนไพรไทย + งานวิจัยจริง ขายออนไลน์จากห้องแล็บเล็กๆ จนวันนี้มีลูกค้าประจำกว่า 40,000 คน

USP

🌿 สมุนไพรไทย + ผ่านแล็บทดสอบการแพ้ · เปิดเผยส่วนผสม 100% · คืนเงินใน 30 วันถ้าแพ้

🗣️ ภาษาแบรนด์ Verbal Identity

โทนเสียง

เป็นกันเองแบบพี่สาว · ให้ความรู้ก่อนขาย · ภาษาไทยง่ายๆ ศัพท์ผิวพรรณอธิบายเสมอ · อีโมจิได้แต่พอดี (ไม่เกิน 2/ประโยค)

คำที่ใช้ (Word Bank)

ผิวแข็งแรง อ่อนโยน ดูแลตัวเอง จากธรรมชาติ เรารู้ว่าผิวแพ้ง่ายเหนื่อยแค่ไหน

คำที่ห้ามใช้

ขาวใน 7 วัน หน้าเด้งเหมือนฉีด ของแท้ 100% (โทนขู่) ด่วน! เหลือ 3 ชิ้นสุดท้าย

✓ ตัวอย่าง on-brand

"ผิวแพ้ง่ายไม่ใช่ความผิดของเราเลยนะคะ 🌿 มาดูกันว่าเซราไมด์ช่วยเสริมเกราะผิวยังไง แล้วทำไมนาราถึงเลือกใช้จากข้าวหอมมะลิไทย"

✗ ตัวอย่าง off-brand

"🔥🔥ด่วนน!! ครีมเทพขาวไวх10 ใครไม่ซื้อคือพลาดมากกก แม่ค้าใจดีลดให้อีก 50฿ รีบกดก่อนหมด!!"

แนวการเขียนต่อแพลตฟอร์ม

Facebook

เล่าเรื่อง+ให้ความรู้ ยาวได้ ปิดท้ายชวนคุยในคอมเมนต์

TikTok

hook 3 วิแรกด้วย pain ผิว สั้น กระชับ ลงท้าย CTA เบาๆ

IG

ภาพสวยนำ แคปชั่นสั้น มู้ด minimal + แฮชแท็กไม่เกิน 8

โลโก้ & กติกาการใช้

✓ ใช้: โปรไฟล์เพจ = Icon · ปกวิดีโอ/แพ็กเกจ = Full · เอกสารขาวดำ = Mono · เว้นระยะรอบ ≥ ความสูงตัว N
✗ ห้าม: ยืด/บีบสัดส่วน · เปลี่ยนสีนอก palette · วางบนพื้นลายถี่ · ใส่เงา/effect เพิ่ม

สี Palette (token)

คลิก swatch เพื่อก๊อปค่า HEX

Token Swatch / HEX บนพื้นสว่าง ใช้ทำ
brand.primary สีหลัก — โลโก้ ปุ่ม ไฮไลต์
brand.secondary สีรอง — สโลแกน จุดเน้นอบอุ่น
brand.bg พื้นหลังสื่อ (มืด/สว่าง)
brand.danger โปรโมชันหมดเขต/แจ้งเตือน (ใช้น้อย)
