# AISTAR → Flow (Chrome Extension)

แผงข้าง (Side Panel) สำหรับทีมทำคลิป: ดึง Clip Job จาก AISTAR Talent OS มา**วาง prompt + แนบรูปลง Google Flow** แล้วกด ✅ รายงานสถานะกลับระบบ — ครบจบโดยไม่ต้องสลับหน้าจอ

## ติดตั้ง (ครั้งเดียว ~1 นาที)

1. เปิด Chrome ไปที่ `chrome://extensions`
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** → เลือกโฟลเดอร์ `extension/aistar-flow` นี้
4. ปักหมุดไอคอน AISTAR → Flow ไว้บนแถบเครื่องมือ (กดรูปจิ๊กซอว์ → 📌)

> อัปเดตเวอร์ชันใหม่: `git pull` → กด ⟳ ที่ `chrome://extensions` → **รีเฟรชแท็บ Shopee/Flow ที่เปิดค้างอยู่ 1 ครั้ง** (แท็บเก่ายังรันโค้ดเก่าจนกว่าจะรีเฟรช)

## วิธีใช้

1. เปิด [Google Flow](https://labs.google/fx/tools/flow) ไว้ 1 แท็บ
2. คลิกไอคอน extension → แผงเปิดข้างขวา → ล็อกอินด้วยบัญชี AISTAR (ครั้งเดียว)
3. เลือก Clip Job → เห็น shot ทุกฉากเรียงตามลำดับ (ฉากที่ถึงคิวมีกรอบเหลือง)
4. ต่อฉาก:
   - **▶ วางลง Flow** — แนบรูปภาพนิ่ง + วาง motion prompt ลง Flow ให้อัตโนมัติ → กด Generate ใน Flow เอง
   - ถ้าวางอัตโนมัติไม่เข้า (Google เปลี่ยน UI): **📋 รูป** ก๊อปรูปเข้าคลิปบอร์ด → Ctrl+V ใน Flow / **📋 prompt** ก๊อปข้อความ
   - **✅ gen แล้ว** — อัปเดตสถานะกลับระบบ + เลื่อนไปฉากถัดไป / **ผ่าน** = approve
5. เสร็จงาน: วางลิงก์โฟลเดอร์ Google Drive ในช่องบนหัวงาน → บันทึก (ซิงก์กับหน้า Clip Jobs ในระบบ)

## 📥 ดูดหน้าสินค้า Shopee เข้าระบบ (v1.1)

1. เปิดหน้าสินค้าใน shopee.co.th ตามปกติ (**เลื่อนลงให้ส่วนรีวิวโหลดก่อน** จะเก็บรีวิวได้ด้วย)
2. เปิดแผง AISTAR → การ์ดฟ้า "📥 ดูดหน้าสินค้า Shopee" จะโผล่เอง → กด **อ่านข้อมูลจากหน้านี้**
3. คัดก่อนเข้า: แก้ชื่อ/ราคา/รายละเอียด, เลือกรูปรายใบ, ติ๊ก+แก้รีวิว, **หมวดหมู่จับคู่ให้อัตโนมัติจาก breadcrumb ของ Shopee** (เปลี่ยนเองได้ / สินค้าเดิมที่มีหมวดแล้ว default ไม่เปลี่ยน) แล้วเลือกสินค้าในระบบที่จะเก็บเข้า (หรือสร้างใหม่)
4. กด **🚀 เริ่มดูด** — ระบบทำให้ครบ: รูปเข้าแกลเลอรี (สูงสุด 6) + AI แตก Review Brief (เติมเฉพาะช่องว่าง ไม่ทับของที่กรอกไว้) + AI คัดรีวิว 4–5 ดาวเข้าคลัง
5. ไปเตรียมคอนเทนต์ต่อที่หน้า Products → 📋 ข้อมูลรีวิว — ตอนสร้าง Clip Job ระบบดึงจากสินค้าให้อัตโนมัติ (แผงนี้ไม่ยุ่งกับ Clip Job)

> ถ้า Shopee เปลี่ยนหน้าเว็บจนอ่านไม่ได้: ก๊อปข้อความ/ลากรูปด้วยมือแบบเดิมได้เสมอที่ modal 📋 ข้อมูลรีวิว

## หมายเหตุทางเทคนิค

- MV3 + Side Panel, ไม่มี build step — แก้ไฟล์แล้วกด ⟳ ใน `chrome://extensions` ได้เลย
- การแนบรูปลง Flow ลอง 3 ชั้น: `input[type=file]` → จำลอง paste → จำลอง drag-drop; ถ้าพังทุกชั้น ระบบก๊อปรูปเข้าคลิปบอร์ดให้อัตโนมัติแล้วแจ้งให้ Ctrl+V เอง
- token เก็บใน `chrome.storage.local` เครื่องใครเครื่องมัน; refresh token ต่ออายุอัตโนมัติ
- ไม่กด Generate แทนผู้ใช้ — เลือกโมเดล/สัดส่วน/กด gen เองใน Flow (ตั้งใจ ไม่ใช่ข้อจำกัด)
